# Knight Game
A simple plataformer level that runs on the Xbox 360 hardware, made via Unity with the console's module

It has very basic features, offering free assets, no bg, a wonky jump and double jump inspired by Hollow Knight, and colisions. 
The knight can be moved by using the left joystick/dpad, and jump by pressing the Y button (Unity's default button for the "jump" function)

By default, Unity will add the "made with unity" screen, which i am yet to discover how to remove
