# Knight Game
A simple platformer level that runs on the Xbox 360 hardware, made via Unity with the console's module

It has very basic features, offering free assets, no bg, a wonky jump and double jump inspired by Hollow Knight, and collisions. 
The knight can be moved by using the left joystick/dpad, and jump by pressing the Y button (Unity's default button for the "jump" function)

FlappyBid 360 refers to the original name/goal of the project: A flappy bird clone, which escalated to a simple demo

By default, Unity will add the "made with unity" screen, which i am yet to discover how to remove, although possible.

The .xlast file was either generated by unity, or, most probably, made manually by the Xbox Live Authoring and Submission(?) Tool. This, alongside some code and configurations on Unity, can be used to set the game's ID, miscellanous data and *achievements*, complete with icons, gamerscore (To be verified/tested) and triggers in-game.
